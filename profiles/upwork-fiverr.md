## 4. Proposal templates (5 — situation ke hisaab se bhejein)

### A. Simple website (HTML/CSS)
```
Hi [Name],

I can build this responsive website for you. I've done a similar single-page build
recently — clean HTML/CSS/JS, mobile-first, and easy to update later.

My plan:
1. Confirm the pages/sections and any reference design
2. Build a responsive first version in 2 days
3. Revisions until you're happy

You can see my work here: [portfolio link]

I'm available to start right away. Would you like me to share a quick estimate?

Thanks,
[Your name]
```

### B. WordPress / bug fix
```
Hi [Name],

I can take a look at your site and fix the issues you listed. I work methodically:
first I'll reproduce each problem, then fix one at a time and verify on desktop + mobile.

I've worked on WordPress/Elementor layouts and CSS fixes before. Happy to do a
small first task so you can check my work before giving the full project.

Portfolio: [link]. Available now — when would you like to start?

Thanks,
[Your name]
```

### C. Web app testing (OWASP / QA)
```
Hi [Name],

I can run a structured QA + security check on your web app. I follow the OWASP
top-10 basics (XSS, SQLi, broken auth, CSRF) and standard functional checks:
broken links, forms, responsive layout, and performance basics.

Deliverable: a short report with findings, severity and fix suggestions — no
scary jargon, just what to fix first.

I'm early in my security journey, so my rate is affordable. Happy to show a
sample report format before we start.

Thanks,
[Your name]
```

### D. Flutter / Android app
```
Hi [Name],

I build cross-platform apps with Flutter (currently deepening my mobile skills).
For this project I'd start with the core screens and get a working APK in your
hands early, then iterate on your feedback.

I'll keep the code clean and document how to build it. If you need something
specific (maps, OTP, local storage) I'll confirm feasibility before quoting.

Portfolio + previous work: [link]

Thanks,
[Your name]
```

### E. Web scraping / automation
```
Hi [Name],

I can build the scraper/automation you described using Python (requests +
BeautifulSoup / Playwright). I'll respect robots.txt and add sensible rate
limits so it stays reliable.

Deliverable: a script + a short README with setup and example output.

Happy to do a small proof-of-concept on one page first.

Thanks,
[Your name]
```

## 5. Fiverr gigs (3 ready-to-publish)

| Gig title | Description (short) | Starting price |
|---|---|---|
| `I will build a responsive landing page in HTML CSS JS` | "Clean, mobile-friendly landing page delivered in 24h. Revisions included." | $25 |
| `I will fix your website CSS and responsive issues` | "Send me the broken page — I'll fix layout, mobile view and small bugs." | $20 |
| `I will test your web app and send a simple bug report` | "Functional + OWASP-basics check with clear, actionable findings." | $30 |

**Fiverr tip:** pehle 3 orders kam rate par lo (review + ranking ke liye). Uske baad price badhao.

## 6. Pricing strategy (beginner)

| Stage | Rate |
|---|---|
| Pehle 3-5 gigs | $20–50 fixed / $8–12 per hour |
| 5+ reviews ke baad | $50–150 fixed / $15–25 per hour |
| Jab 20+ reviews | Apna rate khud set karo |

> Rate kam rakhna **_starting strategy_** hai, aapki value nahi. Har delivery ke saath review maangna na bhoolen.

## 7. Roz ka routine (30 min)

- 10 proposals Upwork + 5 Fiverr bids
- Har proposal me client ka naam + uski problem ka zikr (copy-paste nahi)
- Portfolio link har proposal me
- Jinhe reply aaye, unhe 1 ghante me reply karo

## 8. Red flags (avoid karein)

- ❌ "Pay us to get the job" / training fee
- ❌ Advance payment client se maangna (escrow use karein)
- ❌ Free me full project "trial" ke naam par
- ❌ Kisi ke deleti/company ke systems bina permission test karna
