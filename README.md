# 🚀 Job Hunt Kit

Ye folder aapke remote job / freelance search ke liye hai. Sab kuch free tools se banaya gaya hai.

## Folder structure

```
job-hunt/
├── README.md                 ← aap yahan ho
├── portfolio/                ← Portfolio website (GitHub Pages / Netlify par host karein)
│   ├── index.html
│   ├── styles.css
│   ├── script.js
│   └── README.md
├── web-app/                  ← Real web app: "Job Application Tracker" (portfolio piece #2)
│   ├── index.html
│   ├── styles.css
│   ├── app.js
│   └── README.md
├── profiles/
│   └── upwork-fiverr.md      ← Profile bio, headline, 5 proposal templates, pricing
├── leads/
│   └── job-leads.md          ← Real job/gig links with budget and apply notes
└── bug-bounty/
    └── roadmap.md            ← Beginner → VDP → paid bug bounty path
```

## Pehle kya karein (order me)

1. **Portfolio setup** → `portfolio/README.md` padhein. Apna naam/details badlein, GitHub par push karein, Netlify (free) par host karein. URL milega jaise `https://yourname.netlify.app`.
2. **Web app** → `web-app/README.md`. Ye bhi free me host karein. Iska link portfolio me already hai.
3. **Profiles** → `profiles/upwork-fiverr.md` se bio aur proposals copy karein.
4. **Bid karna shuru** → `leads/job-leads.md` se roz 10-15 proposals.
5. **Side quest** → `bug-bounty/roadmap.md` (paise nahi, experience + skill ke liye).

## Important

- **Jhooth mat bolna.** Portfolio me "self-taught beginner" likha hai — sach hai aur clients ko isse problem nahi hai. "5 years experience" jhooth bolkar nahi milta.
- **Pehla gig chhota lo.** $20-50 ka kaam, achha karke do, review lo. Uske baad rate badhana aasan hai.
- **Rozana 10-15 proposals.** Ye number game hai. 100 me se 2-3 reply aate hain — normal hai.
- **Kisi ko advance paise mat do.** Upwork/Fiverr/Freelancer ka escrow use karein.
